## 精选插件

| 分类 | 项目 | 功能 |
| --- | --- | --- |
| 运行时渲染 | [RealtimeMeshComponent](https://github.com/TriAxis-Games/RealtimeMeshComponent) · MIT | UE5 运行时生成网格渲染 |
| 程序化内容 | [PCGExtendedToolkit](https://github.com/PCGEx/PCGExtendedToolkit) · MIT | 图、寻路、空间操作和 PCG 扩展 |
| 角色移动 | [ALS-Community](https://github.com/PanicPetal/ALS-Community) · MIT | UE5.4 社区维护版 Advanced Locomotion System |
| 加载与工作流 | [AsyncLoadingScreen](https://github.com/truong-bui/AsyncLoadingScreen) · MIT | 可配置的异步加载界面 |
| 程序化世界 | [VoxelPluginFreeLegacy](https://github.com/VoxelPlugin/VoxelPluginFreeLegacy) · 许可证待核验 | 体素地形和程序化世界工具 |
| .NET 集成 | [UnrealCLR](https://github.com/nxrighthere/UnrealCLR) · 许可证待核验 | Unreal Engine 与 .NET 集成 |
| Houdini 集成 | [HoudiniEngineForUnreal](https://github.com/sideeffects/HoudiniEngineForUnreal) · 许可证待核验 | Houdini Engine Unreal 插件 |
| Shader 开发 | [UnrealEngineShaderPluginDemo](https://github.com/Temaran/UnrealEngineShaderPluginDemo) · 许可证待核验 | HLSL Pixel 和 Compute Shader 示例 |
| 源码管理与网络 | [UEGitPlugin](https://github.com/ProjectBorealis/UEGitPlugin)、[SocketIOClient-Unreal](https://github.com/getnamo/SocketIOClient-Unreal) · 许可证待核验 | Git 源码管理和 Socket.IO 集成 |

## 分类

- 编辑器工具和工作流扩展
- Gameplay、Blueprint、GAS 和 UI
- 网络和多人游戏
- AI、动画和程序化生成
- 渲染、材质、Niagara 和技术美术
- 音频、XR、输入和平台集成
- 构建、测试和部署

## 使用前检查

使用插件前，请查看许可证、支持的 Unreal Engine 版本、目标平台、维护活跃度、文档和构建说明。列表中的项目归原作者所有，本仓库是独立的精选索引。
