## Categories

- Editor tools and workflow extensions
- Gameplay, Blueprint, GAS, and UI
- Networking and multiplayer
- AI, animation, and procedural generation
- Rendering, materials, Niagara, and technical art
- Audio, XR, input, and platform integration
- Build, testing, and deployment

## What to check

Before adopting a plugin, review its license, supported Unreal Engine versions, target platforms, maintenance activity, documentation, and build instructions. Listed projects belong to their original authors; this repository is an independent curated index.

## Contributing

Open a pull request with the original repository URL, license, supported UE version, and a brief description of the plugin.
